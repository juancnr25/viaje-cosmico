# Viaje cósmico

Material de lectura interactivo y gamificado: la Luna y la Tierra, la Tierra y el Sol, el sistema solar, la Vía Láctea, las galaxias vecinas, la expansión del universo y el mundo cuántico, con 12 simulaciones.

- PWA instalable en Android e iPhone, funciona sin conexión.
- Temas oscuro, claro y verde bosque.
- Sin dependencias externas: HTML, CSS y JavaScript puros.

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.

## Actualizar
Cada vez que cambies `index.html`, sube también `sw.js` con un nuevo valor de `VERSION`. Así los celulares que ya la instalaron reciben el aviso de actualización.
